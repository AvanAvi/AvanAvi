## 🥷 Status: stealth

I spend my days on industrial automation and safety-critical software. I can't tell you more than that, which makes for a short pitch and an excellent excuse for an empty commit history on the interesting parts. I also build some genuinely cool internal tools every day for work, and no, I won't be mentioning them here. What I can show is what I build on my own time, below.

## 🧪 What I'm building

| Project | What it is | Stack | Mode | Status |
|---|---|---|---|---|
| [**mini-rag**](https://github.com/AvanAvi/mini-rag) | A small retrieval-augmented generation project, built one pull request at a time so every design choice is visible in the history | Python | 📡 public | 🟢 active |
| **proof-crawl** | A web scraper in Rust that records where each piece of data came from, so a scraped result can be traced back to its source page | Rust | 📡 public | 🟢 active |
| **Standards checker** | Reads safety software evidence against standards (IEC 61508 family) and flags the gaps a reviewer would find at the worst moment | Python | 🛩️ stealth | 🟡 designing |
| **mcp-capability-proxy** | A proxy that sits between an agent and its MCP tools and enforces what the agent is allowed to do | Python / Rust | 🛩️ stealth | 🟡 designing |

<sub>Mode: 📡 public means built in the open, 🛩️ stealth means no radar signature until it's worth showing. Status: 🟢 shipping, 🟡 in design.</sub>
